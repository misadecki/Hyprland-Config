In this setup I used a lot of AI stuff and took inspiration from git repository by [Firstp1ck](https://github.com/Firstp1ck/Hyprland-Simple-Setup)

Especially wallpapers are the one of the most significant things that I use in
my OS from this repository. Other things are rofi and waybar styles.

My aim was to make a simple floating window environment for terminal use in Arch
theme (and prepare it for my invert workflow). I hope to introduce more things to make my configuration perfect for me (especially keyboard shortcuts).

### Programs I use
- Command prompt: Starship
- Display managment: mng-displays
- Image viewer: swayimg
- Document viewer: okular
- Wallpaper slideshow: awww
- Network: network-manager (nmcli/nmtui)
- Videos: VLC
- Password manager: KeePassXC
- AI: Google Gemini
- Internet: Firefox (but I'm searching for something more secure)
- GUI file manager: Dolphin (it's not good working with Hyprland)
- Calculator: Qalculate-gtk
- Text editor: NVim
- Communication: Vesktop (discord fork)
- Terminal: kitty
- Shell: zsh
- Notifications: swaync
- Menu: rofi
- Clipboard: wl-clipboard
- Hand writing: xournalpp
- Tablet: opentabletdriver
- Screenshots: grim + swappy (I'm searching for something else)
- Additional terminal: pypr
